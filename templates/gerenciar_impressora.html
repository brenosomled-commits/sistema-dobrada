Configuração da Elgin i9 (80mm) — gerência

Configuração

Somente gerente
Quando ativado, o botão 🖨 Zebra tenta imprimir direto via Web Serial. Na primeira vez em cada máquina é necessário selecionar a porta.

Como deixar automático em todas as máquinas

  1. Em cada computador, abra Entregas e clique em 🖨 Zebra — na primeira vez selecione ELGIN i9 (USB) ou USB Serial e marque “Lembrar” se aparecer. Depois fica automático.
  2. Para o botão 🖨 normal (navegador), defina a Elgin como padrão no Windows: Painel de Controle → Dispositivos e Impressoras → botão direito na Elgin i9 → Definir como padrão.
  3. Mantenha o Chrome/Edge atualizado e use https (Vercel já é https).
  4. Se o diálogo ainda mostrar “Brother”, é porque a padrão ainda é a Brother — altere no Windows.
Dica: A impressão direta via Web Serial funciona em Chrome/Edge desktop. No celular, use o botão 🖨 normal (80mm) — o sistema já está com @page 80mm auto e cupom negrito.
