Configuração da Elgin i9 (80mm) — gerência

Configuração

Somente gerente
A Elgin i9 é compartilhada na rede. A impressão universal usa a impressora padrão do Windows de cada máquina — funciona em todos os computadores, inclusive via acesso remoto.

Como deixar universal em todas as máquinas

  1. A Elgin i9 já está compartilhada na rede Windows. Em cada computador (local ou via acesso remoto), abra uma entrega e clique em 🖨 Zebra — o sistema usa a impressora padrão do Windows daquela máquina.
  2. Para garantir que seja a Elgin: Painel de Controle → Dispositivos e Impressoras → botão direito na Elgin i9 → Definir como padrão. Faça isso uma vez em cada computador.
  3. Na primeira impressão em cada máquina, o Windows pode pedir para confirmar a impressora — escolha a Elgin i9 e marque “Usar por padrão”, se aparecer.
  4. Se o diálogo mostrar outra impressora (ex.: Brother), basta trocar para a Elgin no seletor de impressora do próprio diálogo — fica lembrado depois.
Como funciona a conexão universal: os computadores acessam a Elgin i9 por acesso remoto à impressora compartilhada na rede. O navegador imprime pela impressora padrão do Windows, e o próprio Windows envia para a Elgin compartilhada — funciona em qualquer máquina, sem depender de porta USB local. A opção “Só via USB local” (Web Serial) é apenas para quando a Elgin estiver plugada direto no próprio computador.
